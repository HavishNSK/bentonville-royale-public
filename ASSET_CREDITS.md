## Crystal Bridges paintings (`public/art/crystal-bridges/`)

Every file below is a public-domain painting in the collection of the Crystal Bridges Museum of American Art.

- **Source and rights:** the image comes from the museum's own collection record, which states `"copyright": "Public Domain"`, except Kindred Spirits, which comes from the museum's public-domain release on Wikimedia Commons.
- **Credit:** courtesy of Crystal Bridges Museum of American Art.
- **Machine-readable record:** `public/art/sources.json`, which has per-file SHA-256, source URL and photography credit. It is written by `scripts/fetch-cb-art.mjs`.
- **Accepted rights:** only Public Domain / CC0 / CC BY files are fetched. A record marked "Public Domain - Orphaned Work" was rejected.
